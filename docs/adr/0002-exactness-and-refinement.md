# Exactness and refinement have distinct claims

Status: accepted design decision, 0.1.0-draft.

## Decision

Complete executable specs may request observable equivalence. General contracts request refinement. Underdetermined exact-mode tasks return NeedsDecision/Unsupported.

## Consequences

This prevents a correct implementation of one permitted choice being advertised as equality with every allowed behavior.

## Validation

The corresponding normative documents, requirement registry and milestone acceptance evidence must agree. This decision does not claim its implementation exists.

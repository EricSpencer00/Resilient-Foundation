# Generation proposes; deterministic checking accepts

Status: accepted design decision, 0.1.0-draft.

## Decision

LLMs propose requirements, code and proof hints. Locked intent/specs and deterministic evidence policies control acceptance. No judge vote upgrades Unknown into Proved.

## Consequences

Better models improve yield/cost, while the acceptance rule remains stable across model releases.

## Validation

The corresponding normative documents, requirement registry and milestone acceptance evidence must agree. This decision does not claim its implementation exists.

# Separate model, package and runtime evaluation

Status: accepted design decision, 0.1.0-draft.

## Decision

Freeze artifact corpora for deterministic package measurements. Run new models on pinned end-to-end tasks/scaffolds. Keep official SWE-bench outcomes separate from formal/translation claims and adaptations.

## Consequences

This isolates gains from stronger models, better verification infrastructure and faster produced code.

## Validation

The corresponding normative documents, requirement registry and milestone acceptance evidence must agree. This decision does not claim its implementation exists.
